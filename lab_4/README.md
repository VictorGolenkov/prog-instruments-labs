# Технологии и методы программирования

## Лабораторная работа №4 «Рефакторинг»
В рамках данной лабораторной работы требуется продемонстрировать талант к проведению структурных улучшений в коде проекта.

## Описание сделанных изменений:
1) Произведён рефакторинг функций валидации:
    - функции `_roll_validate()` и  `_marks_validate()` объединены в одну, чтобы убрать нарушение принципа DRY;
    - из функций валидации убраны однобуквенныые переменные, улучшена логика условий;
    - функции более не взаимодействуют напрямую с GUI (SRP), вместо этого отправляют отчёт об ошибке;
    - использование функций валидации (там где они вызывались) переделано;
    - `validate_string()` и `validate_integer()` объединены в класс `ValidationFunctions` и вынесены в модуль `Validation.py`.
2) Создан класс студента для улучшения сопровождаемости:
    - функция `validate_student` сделана статическим методом класса `Student`.
3) Произведён рефакторинг функций `f9()`, `f11()`, `f12()`:
    - `f9()`, `f11()`, `f12()` переименованы в `create_entry()`, `update_entry()`, `delete_entry()` соответственно;
    - SQL-запросы сделаны параметризированными, чтобы устранить уязвимость SQL-инъекции;
    - упрощён алгоритм добавления записи в базу данных, убран не нужный цикл;
    - функция разбита на несколько функций по задачам: валидация, работа с базой данных, управляющая функция.
4) Переделаны функции `loc()` и `temp()`:   
    - используется f-строки вместо конкатенации через "+";
    - изменены названия функций и переменных;
    - функции объединены в класс `APIService` и вынесены в отдельный модуль `APIService.py`
    - захардкоженные значения вынесены в константы.
5) Функции `f3()` и `f13()` переделаны:
    - переименованы в `view_entries()` и `display_students_chart()` соответственно;
    - логика работы с базой данных вынесена отдельно;
    - сами функции поправлены: теперь используются f-строки вместо конкатенации через "+".
6) Функции, отвечающие за работу с базой данных убраны в отдельный класс и модуль.
7) Функции работающие с GUI объединены в один класс и оставлены в `main.py`.

Прочее:
    - добавлены docstring;
    - сделаны отступы согласно pep8;
    - табуляции заменены на 4-ре пробела;
    - исправлены названия переменных и функций;
    - импорты исправлены в соответствии с pep8;
    - исправлен баг, теперь окно обновления закрывается после нажатия кнопки "Back";
    - функция вывода фразы дня убрана, так ресурс не доступен в РФ.
